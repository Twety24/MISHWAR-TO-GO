# Mashaweer | مشاوير

English-first, left-to-right static website concept inspired by everyday Egyptian city movement, with a one-click Arabic/RTL language switch.

## Files
- `index.html` — website structure and copy
- `styles.css` — responsive style system for desktop/mobile and RTL
- `script.js` — language switching and interactive local trip-summary demo
- `brand/mashaweer-logo.svg` — full vector wordmark
- `brand/mashaweer-mark.svg` — standalone vector brand mark
- `images/` — original SVG vehicle illustrations

## Run
Open `index.html` in a modern browser. Google Fonts load online; system fallback fonts are used offline.

## Important
This is a front-end concept only. It does not connect to real drivers, bookings, payment, accounts, maps, or a backend. The form creates a local summary only. Domain and trademark availability have not been legally verified.
